INDRA INTERACTIVE PROTOTYPE
===========================
Open index.html in Chrome/Safari.

Prototype flow:
Home -> Ask INDRA AI / Explore Map / Hazards / Alerts / Resources
Explore Map -> click hazard pins -> Hazard Detail
Alerts -> click an alert -> Hazard Detail
Ask INDRA AI -> type a question -> prototype grounded-response state
Resources -> medical / police / NGO routing buttons

This is a front-end demonstration based on the INDRA project brief. It uses simulated UI responses and should not be treated as live emergency information.
